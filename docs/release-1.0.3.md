# Seen 1.0.3 — двойные галочки

Дата: 30.09.2026. Plugin ID: `ru.internal.mattermost.seen`.

Текстовые символы ✓✓ заменены собственным SVG по предоставленным референсам Telegram: два близко расположенных штриха, сокращённое плечо второй галочки, скруглённые концы. Иконка 18×12 px, толщина штриха 1.6 в viewBox 20×12. Это приближённое воспроизведение по скриншотам, не извлечённый оригинальный asset Telegram и не обещание пиксельного совпадения на всех экранах.

Для просмотренных сообщений — голубой оттенок с небольшой адаптацией к цвету текста Mattermost theme; непросмотренные — серый theme color. Счётчик group/channel отделён от иконки зазором 3 px. В DM отображается только иконка. SVG декоративный (aria-hidden), описание статуса остаётся на кнопке. Состояния expired/unknown сохраняют свои отдельные обозначения.

Backend, настройки хранения, дата Сегодня/Вчера, viewport dwell и first timestamp не изменены. Обновлены manifest/package version и changelog. Архивы прошлых версий не заменены.

Установка: загрузить .tar.gz как обновление того же плагина, убедиться в версии 1.0.3, reload web/desktop клиентов. Проверить серые и голубые галочки, DM/group, обе темы, hover, клавиатуру/ESC, конец сообщения и 125% zoom. Полный набор приёмки 1.0.2 остаётся применимым; это визуальный patch. При переходе с 1.0.0 сохраняется требование согласованного обновления всех app-нод для tombstone fix, введённого в 1.0.1.

Локальная сборка и mock browser smoke протоколы приложены в отдельном архиве проверок; live Mattermost прогон не заявляется. Нужны финальная визуальная проверка в вашем клиенте и подтверждение предпочтительного цвета/масштаба.
