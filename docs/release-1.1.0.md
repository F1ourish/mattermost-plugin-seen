# Seen 1.1.0 — короткий предпросмотр и полный список

Дата: 05.10.2026. Статус: кандидат для проверки на тестовом Mattermost. ID: `ru.internal.mattermost.seen`.

## Что изменилось

Popover показывает общий счётчик и первые пять пользователей в порядке первого просмотра. При количестве больше пяти появляется нижняя кнопка «Показать всех · N →». Для preview запрашивается только пять receipts; scroll не подгружает остальные. На очень низком viewport допустима защитная прокрутка пяти строк, чтобы footer оставался доступным.

Кнопка открывает полный список в адаптивном окне шириной до 460 px. Заголовок со счётчиком и закрытием остаётся неподвижным, строки прокручиваются с загрузкой API-страниц по 50. По нажатию на галочки полный список по-прежнему открывается напрямую. После закрытия фокус возвращается на индикатор сообщения, в том числе при переходе через footer предпросмотра.

Пустой список, loading/error/retry, light/dark, RU/EN и Сегодня/Вчера сохранены. Backend и зависимости не менялись. Новая версия minor: совместимое расширение UI. Старые релизные файлы не перезаписаны.

## Установка и проверка

Сохранить предыдущий пакет и настройки. Проверить SHA256SUMS-1.1.0.txt рядом с файлами командой `sha256sum -c SHA256SUMS-1.1.0.txt`. Загрузить ru.internal.mattermost.seen-1.1.0.tar.gz через управление плагинами, проверить версию и reload Web/Desktop. Для перехода с 1.0.0 остаётся обязательным согласованное отключение/обновление всех app-нод из-за tombstone fix.

На тестовом контуре проверить:

| Сценарий | Ожидаемый результат |
|---|---|
| 0 viewers | Пустое состояние, нет Show all/лишних кнопок |
| 1, 5 viewers | Все строки видны, footer отсутствует |
| 6, 70 viewers | В preview пять строк, верный общий count и Show all |
| Открыть preview, оставить на обновление | Viewers requests только offset=0, limit=5; нет загрузки полного списка |
| Show all мышью / Enter | Один полный диалог; preview закрывается |
| Длинный список | Подгрузка при прокрутке, шапка неподвижна, имя и время сопоставимы |
| ESC / крестик / click outside | Диалог закрывается, фокус на индикаторе |
| Ошибка / отозванный доступ | Retry либо очистка недоступных viewers; старые данные не выдаются за успешный ответ |
| Light/dark, 125% zoom, узкий viewport | Контент доступен, окно не выходит за экран |
| Повторный просмотр / author-only | Timestamp/count неизменны от дубля; чужой список недоступен |

Полная [матрица](acceptance-1.0.2.md) остаётся применима с текущим именем пакета. Live результаты этой версии пока NOT RUN. Локальные mock browser проверки не заменяют Mattermost gateway/HA acceptance. При проблеме отключить плагин; rollback на ранее проверенную 1.0.3 выполнять согласованно по [ранбуку](operations.md), без очистки KV.
