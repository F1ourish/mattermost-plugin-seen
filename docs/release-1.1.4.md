# Seen 1.1.4 - исправление позиции индикатора и обновление зависимостей

Дата: 30.10.2026. Статус: кандидат, не опубликован. Целевой Mattermost: 11.10.x; другие версии, включая 12.0, требуют отдельной проверки.

## Причина и изменение

При добавлении описания перед двумя ссылками React может сохранить элемент абзаца, удалить прежние дочерние узлы и вставить новые после контейнера Seen. Плагин ранее проверял только родителя контейнера, поэтому индикатор мог остаться первым элементом сообщения.

Теперь проверяется также позиция: контейнер Seen должен быть последним дочерним узлом выбранного абзаца. Перемещается только собственный контейнер плагина. Текст, ссылки и отметка редактирования Mattermost не изменяются. Происхождение сообщения из мобильного клиента не требуется для воспроизведения.

Исходники backend, ID плагина, KV, первые timestamps и условия сбора просмотров не меняются. Сохраняются Web/Desktop-only сбор и attachment fallback для сложной разметки.

## Обновление безопасности

Первый CI кандидата 30.10.2026 остановился на source scan: GO-2026-6809 относится к достижимому `crypto/x509.Certificate.Verify` в Go 1.26.9. Release compiler, go directive и build/security scripts обновлены до Go 1.26.10. Дополнительно `golang.org/x/net` обновлён с 0.60.0 до 0.62.0 для GO-2026-6866 и GO-2026-6860, отмеченных сканером на уровне импортированного package без найденного вызова уязвимого символа.

Go tooling формирует итоговые `go.mod`/`go.sum`; inventory и лицензии генерируются из compiled dependencies. Серверные исходники сохранены, но бинарники обеих архитектур пересобираются и имеют новые закреплённые SHA256. Совпадение серверных бинарников с 1.1.2/1.1.3 больше не заявляется. Module-only GO-2026-5932 в OpenPGP остаётся известным ограничением: исправленной версии нет, package не импортируется плагином; scan не подавляется.

Следующий локальный `npm audit` обнаружил GHSA-mrhx-c7xc-m3w5 в Zod 4.6.5. Это транзитивная dev dependency `eslint-plugin-react-hooks`, не часть поставляемого web bundle. Адресное обновление lockfile через npm закрепляет Zod 4.6.7 в допустимом диапазоне родительской зависимости; direct dependencies не меняются. Проверки ESLint, frontend build и audit выполняются заново.

Официальные источники: [GO-2026-6809](https://pkg.go.dev/vuln/GO-2026-6809), [GO-2026-6866](https://pkg.go.dev/vuln/GO-2026-6866), [GO-2026-6860](https://pkg.go.dev/vuln/GO-2026-6860), [GHSA-mrhx-c7xc-m3w5](https://github.com/advisories/GHSA-mrhx-c7xc-m3w5). Результат актуального source/binary scan и npm audit брать из успешного exact CI run, не из первого неуспешного прогона или исторических отчётов.

## Проверки

Browser mock воспроизводит две ссылки с мягким переводом строки и с BR, добавляет описание и повторно редактирует его при сохранении того же абзаца и кнопки Seen. Проверяются конец абзаца, единственная кнопка, неизменённые URL, fallback после code block и повторное присоединение после замены Markdown. До исправления проверка конца абзаца падает.

Автоматические проверки и полный SHA256 привязываются к конкретному CI run. Приёмка на живом Mattermost, длительная сессия и HA для этого кандидата остаются NOT RUN. Успех browser mock не является проверкой совместимости с Mattermost 12.0.

## Установка и откат на тестовом контуре

Скачать `seen-candidate` из успешного CI нужного commit. Разместить его файлы в каталоге `dist` и из родительского каталога выполнить `sha256sum -c dist/SHA256SUMS`. Сверить `source_commit` и `workflow_run_id` в `release-validation-1.1.4.json` с выбранным запуском.

Сохранить предыдущий пакет и настройки. Загрузить `ru.internal.mattermost.seen-1.1.4.tar.gz` через System Console как обновление того же ID, проверить версию/активацию и перезагрузить Web/Desktop. Полный порядок приведён в [README.ru.md](../README.ru.md).

Повторить исходный сценарий с двумя тестовыми ссылками и описанием, проверить повторное редактирование, обе темы и открытие списка просмотров. До обновления полная перезагрузка клиента заново размещает индикатор; это временный обход.

Откат к 1.1.3 того же ID совместим с форматом KV, но возвращает указанные Go/x/net advisories и ошибку позиции индикатора. При security rollback оставить Seen отключённым до появления совместимого исправленного пакета. Удалять Plugin KV не требуется; на время отключения отсутствуют индикаторы и сбор новых отметок. Существующие release assets не заменяются; действующие helpers не публикуют 1.1.4 автоматически.
